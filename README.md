# Flappy Penguin 🐧
Jeu HTML/CSS/JavaScript sans dépendance, prêt pour GitHub Pages.

## Publication
1. Créez un dépôt GitHub public.
2. Déposez `index.html`, `styles.css` et `script.js` à la racine du dépôt.
3. Dans **Settings → Pages**, choisissez **Deploy from a branch**, branche **main**, dossier **/(root)**, puis **Save**.
4. Ouvrez l'URL GitHub Pages fournie après déploiement.

## Commandes
Espace, flèche haut, clic ou toucher pour battre des ailes. P ou Échap pour pause. Le record est sauvegardé dans le navigateur.
